AXTEC AI — backend demo

This page mounts the AXTEC AI widget against this same backend (running locally on this server). Click the floating button in the bottom-right corner to try it.

Check /api/health to confirm the server is up and which data/AI mode it's running in.

To embed this widget on the real AXTEC site, copy axtec-ai-widget.css and axtec-ai-widget.js there and point data-api-base at this backend's public URL.
